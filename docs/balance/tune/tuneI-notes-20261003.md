# 普通の野球へ: 塁でのフォースアウト・デッドボールは出塁 — 所見 2026-10-03

## 変更

- アウトは「走者が着く前に、その走者が向かっている塁へ球を届ける」（投げる、または 320px/s 以下で持って運ぶ）。打てば走者は全員進むので全部フォースプレー。走者に当てる方式は廃止。
- 投げるべき塁を赤く点滅。走者は普通の色（的の輪・点滅なし）。「塁に投げろ！」。
- デッドボールは打者が1塁へ（以前は守備側に1点）。
- ボット: 守備は「間に合う塁のうち一番先の走者」へ投げる（60px 以内なら持って運ぶ）。走者は止まってよけない。投手は指を狙わない。

## 読み

1. **アウト率を決めているのは送球の速さではなく走者の速さ。** 送球を 0.6 → 0.45 倍にしてもアウト率は 82% のまま。ボットは間に合う塁にしか投げないので、間に合うかどうかは走者が塁に着く時間でほぼ決まる。
2. 走者の速さは、以前「止まって避ける」遊び方のために 70% に下げてあった。塁で刺すルールでは足りないので、1タップの加速だけを 1.43 倍（43 → 61.5）に戻した。
3. 上限（runnerBoostMax）は秒 6 回を超える連打でしか効かない。中級の結果は変わらず、上級の点の入りすぎだけを決める。165 を採用。
4. 採用値で中級同士は平均 2.9 点・アウト率 70%（実際の野球の 3 回ぶん・インプレーのアウト率に近い）。
